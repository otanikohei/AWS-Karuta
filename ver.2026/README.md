# AWS-Karuta ( AWSかるた )
AWS かるた version.2026 は、10 年前に誕生した AWS かるたを現在のサービスとアイコンにリニューアルしたものです。  
AWS かるたは、AWS のサービスや機能を楽しみ遊びながら自然と覚えて行けるゲームとして、10 年前にリリースされました。  
本バージョンは、従来の AWS かるたの良さを活かしつつ、百人一首のような競技かるたを目指してリメイクしました。

## 絵札について
絵札は、競技用かるたと同じ 横: 52mm、縦: 73mm にてデザインしています。  
等倍での印刷を推奨します。

## ディレクトリ構成

```
ver.2026/
├── game/            ... ゲーム本体（S3等でホスティング）
│   ├── index.html         かるたゲーム（10問チャレンジ）
│   ├── reader.html        読み上げモード
│   ├── images/            取り札画像
│   └── audio/             読み上げ音声 (mp3)
├── scripts/         ... 開発用スクリプト（ホスティング不要）
│   └── create-audio.sh   Polly で音声ファイルを生成
└── README.md
```

## ホスティング

`game/` ディレクトリを S3 静的ウェブサイトホスティング等にアップロードしてください。  
`scripts/` は開発用のためアップロード不要です。

## 音声ファイルの再生成

音声は Amazon Polly (Neural, Tomoko) で生成しています。

```bash
cd ver.2026/scripts
bash create-audio.sh
```

AWS CLI の認証情報が必要です。生成された mp3 は `game/audio/` に出力されます。
